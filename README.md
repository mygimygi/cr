# 깡총깡총 길건너기 (cr)

차, 강, 기차를 피해 최대한 멀리 가는 블록 스타일 길건너기 게임입니다. 이 파일 하나만 있으면 브라우저에서 바로 실행돼요.

## 실행

`index.html`을 브라우저에서 열면 됩니다. (three.js는 cdnjs에서 불러오므로 인터넷 연결이 필요해요.)

## 조작

- 방향키 / WASD: 이동
- 스페이스 / 엔터: 앞으로 (게임 오버 시 다시 시작)
- 모바일: 탭 = 앞으로, 스와이프 = 방향

## 기능

- 도로(승용차·트럭·버스·경찰차·고속 차선), 통나무 강, 연잎 강, 철도(신호등과 기차)
- 나무·바위·그루터기 장애물, 동전 수집
- 제자리에 오래 있거나 뒤처지면 독수리가 잡아감
- 동전 50개로 캐릭터 뽑기 (직접 디자인한 12종: 기본·보통·희귀·전설 등급)
- 3분마다 받을 수 있는 동전 선물
- 최고 기록·동전·캐릭터는 브라우저 localStorage에 저장
